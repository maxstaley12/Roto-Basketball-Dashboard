Definitions and caveats
  • Search clicks, impressions, position: Google Search Console, web search only. Discover and News are not included, which is one reason GA4 organic sessions run higher than clicks.
  • Sessions: GA4 sessions whose landing page is under /basketball/article/. "Organic" means the Organic Search channel group; "all-channel" includes direct, email, social, referral and AI assistants.
  • Purchases: the GA4 purchase key event on sessions that landed on these articles, across all channels. A buyer who reads an article and purchases in a later session is credited to that later session's landing page.
  • Topics (pie charts): each landing page is placed in the first topic whose keywords match its URL (for example "mock-draft" or "cheat-sheet"; the keyword list is in the project's config file). Both pies count organic search only, by landing page, so the purchase pie total will not match the all-channel Purchases card. Landing pages GA4 does not itemize (about 3% of article sessions) are counted under "Everything else" so the pie matches the Organic sessions card. Purchase counts are small, so a few pages can swing a slice.
  • Articles published (est.): Shown for the Articles view only. a count of /basketball/article/ URLs in the sitemap, dated by estimated publish date (each article's ID order combined with last-modified times, so later edits are not counted as new articles). Articles deleted since publication are not in the sitemap, so last year's count may be understated. This is a snapshot and does not refresh with the other cards.
  • Window: 27 days, ending Nov 15. Search Console data lags a couple of days, so the latest end date you can pick is two days ago. Last year's comparison is always the same dates shifted back 364 days so weekdays line up. Ranges of 21 days or fewer are charted by day; longer ranges by week, counted from your start date, and a final partial week is marked in the tooltip.
  • Year over year: article mix, publishing volume and the NBA calendar differ between seasons, so treat it as directional.
